# PERMISSIONS

What Fathom vendors or bundles, and the basis on which it does.

## Vendored RTL

### Ibex — the simulated core

- **Upstream:** https://github.com/lowRISC/ibex
- **Pinned commit:** `34b0705760ef3dfa00e99637432473d2be8f22f3` (2026-08-31)
- **Licence:** Apache-2.0 (`vendor/ibex/LICENSE`)
- **Basis:** Apache-2.0 is permissive and compatible with distribution inside an
  AGPL-3.0 work. FATHOM.md §4.5 requires a permissive licence
  (Apache-2.0 / ISC / BSD class); this satisfies it.
- **Modified:** no. Vendored unmodified, then pruned to the subtrees `forge` reads
  (57 MB -> 3.3 MB; see `vendor/ibex/FATHOM-VENDOR.md` for exactly what was dropped).
  Configuration is by
  parameter only, applied at synthesis time in `forge/synth/synth.ys` — no
  source edits, so the pin can be moved without re-deriving a patch set.
- **Attribution:** Ibex is a lowRISC project. Fathom does not claim authorship of
  the core, and every layer that renders it names it.

Ibex vendors further code under `vendor/ibex/vendor/` — lowRISC `prim` cells
(Apache-2.0) are kept and used by the synthesis flow. Google `riscv-dv`, EEMBC
CoreMark, `riscv-isa-sim`, `riscv-arch-tests` and `pulp_common_cells` are in the
upstream clone, are **not** used by Fathom, and were dropped in the prune — so
they are neither built nor distributed.

## Toolchain — used to build, not distributed

LLVM/clang and ld.lld (Apache-2.0 with LLVM exception), Yosys (ISC), sv2v (BSD-3),
Icarus Verilog (GPL-2.0), Verilator (LGPL-3.0 / Artistic-2.0). All are build-time
tools that run offline in `forge`; none is bundled into a descent artifact or into
`fathom.html`, so their terms do not reach the shipped work.

## Bundled artifacts

Descent artifacts under `artifacts/` are generated by `forge` from Fathom's own
program source and the vendored core. They contain no third-party content beyond
net and module names derived from Ibex's RTL, which the Apache-2.0 grant covers.
